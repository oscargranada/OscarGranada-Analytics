## ✅ Caso práctico: Análisis de rendimiento escolar en NYC – SAT Scores

Herramientas: Python

Exploración de datos públicos sobre escuelas de Nueva York.
- Análisis exploratorio con pandas y visualización de KPIs.
- Identificación de escuelas con alto rendimiento en matemáticas.
- Ranking de escuelas por puntaje SAT combinado (math + reading + writing).
- Evaluación de variabilidad por distrito (borough) y reflexión sobre desigualdad educativa.
- Caso documentado como notebook ejecutable en Python.
